# 数据准备

本仓库**不包含**交通流数据本体，也不包含任何真实气象或事故记录。请按下表下载后放入本目录。

## 需要的文件

| 数据集 | 文件 | 说明 |
| --- | --- | --- |
| PEMS08 | `pems08.npz` | 170 个检测器，5 min 粒度，2016-07-01 至 2016-08-31 |
| PEMS08 | `distance.csv` | 检测器距离表，含 `from`、`to`、`cost` 三列 |
| PEMS04 | `pems04.npz` | 307 个检测器，2018-01-01 至 2018-02-28 |
| METR-LA | `metr-la.h5` 或转换后的 `metr_la.npz` | 207 个检测器，2012-03-01 至 2012-06-30 |

## 下载来源

以上三个数据集均为公开数据，常见发布渠道：

- PEMS04 / PEMS08：ASTGCN 官方数据仓库 <https://github.com/guoshnBJTU/ASTGCN>
- METR-LA：DCRNN 官方数据仓库 <https://github.com/liyaguang/DCRNN>
- 也可从 Graph WaveNet、STSGCN 等公开实现的 `data/` 目录获取同名文件

下载后请核对文件形状与时间范围：

```
pems08.npz  ->  data: (17856, 170, 3)
pems04.npz  ->  data: (16992, 307, 3)
```

本实现取通道 0 作为交通流量，通道 1、2 分别为速度和零速车辆比例。

## 关于外部语义特征

天气、节假日、事故等语义特征**不需要额外数据文件**，由 `src/semantic.py` 按固定随机种子生成，规则见根目录 README。若后续研究中接入实测气象站记录或真实事故报告，请替换该生成函数，并在论文中补充数据来源、字段编码与站点时空匹配方式。
