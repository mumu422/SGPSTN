# 代码与论文的差异清单

开源或投稿补充材料前，请逐条确认。下表列出**当前实现**与**论文正文描述**的不一致处，供作者决定是改代码还是改文字。

| 位置 | 论文描述 | 当前实现 | 建议 |
| --- | --- | --- | --- |
| 2.1 动态邻接矩阵 | 逐时间步按 Pearson 相关系数、窗口 L=6、阈值 θ=0.7 重构 A(t)，再对称化归一化 | 由 `distance.csv` 构造静态反距离图，1/(distance+ε)，对称化后最大值归一化；无数阈值与逐时间步更新 | 实现 Pearson 动态图，或把论文改为静态图 + 自适应权重 |
| 2.3 注意力投影 | Query 投影共享，Key 分时间与空间两套 | 时间、空间各有一套独立 Q/K/V 投影 | 共用 Q 权重，或论文改为“分别投影” |
| 2.5 损失函数 | 总损失 = NLL + λ1·MAE + λ2·尺度正则 | `model.compile` 仅使用 NLL；MAE 作为 metric，正则项未实现 | 补两项加性损失，或论文删去 λ 叙述 |
| 3.2 网络规模 | 图卷积 4 层、隐藏维 128；BiLSTM 2 层、隐藏 256 | 图卷积 1 层、units=64；BiLSTM 64 + LSTM 128 | 参数化层数与隐藏维后按论文设置重跑 |
| 3.2 训练设置 | Adam 1e-3、余弦退火、batch=32、早停 | Adam 1e-3、无学习率调度、batch=32（已对齐）、EarlyStopping patience=10 | 补余弦退火；其余已一致 |
| 3.5 消融 | “移除语义引导机制” | 实际是把语义特征置零、注意力模块保留 | 文字改为“将外部语义特征置零以屏蔽其引导作用” |
| 3.1 数据来源 | 早期稿件称天气“从公共气象数据集获取” | 全部由 `src/semantic.py` 仿真生成 | 已改为仿真表述，不要再声称实测气象 |
| 语义维度 | 正文以 $d_c$ 泛写 | 实际 8 维，拼接不确定性后 16 维 | 论文写明 8 维与 16 维 |

## 尚未完成

- 未跑完整训练、未重算论文表格数值。
- 仓库不含绘图代码，论文中的趋势图、热力图、区间图与不确定性分布图均由作者另行绘制，仓库只输出终端指标。
- 未实现多步（H>1）联合输出，目前为单目标预测；论文若声称“输出未来 12 步”，需扩展输出层。
- 未提供基线模型实现（STGCN、ASTGCN、PDFormer、STUP 等），对比实验需各自独立复现。
