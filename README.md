# SGPSTN：语义引导的概率时空网络

Semantic Guided Probabilistic Spatiotemporal Network (SGPSTN)

本仓库给出论文《基于语义引导概率时空网络的交通流预测》的模型实现、训练评估入口与外部语义特征生成规则，用于复现与核对。

**重要说明（数据性质）**

- **交通流数据是真实的公开数据集**：PEMS04、PEMS08、METR-LA，需按 `data/README.md` 自行下载，仓库不分发数据本体。
- **天气、节假日、事故等外部语义特征是程序仿真生成的**，不是实测气象或事故记录，也不是论文所称的“多源实测数据”。它们用于检验语义引导机制，固定随机种子即可逐位复现。
- 语义标记不改变真实流量，因此本仓库不构成具有事故冲击真值的交通仿真。

## 环境

Python 3.9 及以上，深度学习框架 TensorFlow 2.x + TensorFlow Probability。已验证的组合见 `requirements.txt`。

```bash
pip install -r requirements.txt
```

GPU 非必需；CPU 可跑通，但训练较慢。

## 数据准备

1. 按 `data/README.md` 下载 `pems08.npz` 与 `distance.csv`（或 PEMS04 / METR-LA 对应文件）。
2. 放入 `data/` 目录，保持如下结构：

```
data/
├─ pems08.npz        维度 (时间步, 节点, 特征)，本实现取通道 0 作为流量
└─ distance.csv      传感器距离表，至少含 from / to / cost 三列
```

3. 时间粒度 5 min，输入窗口 `L=12`（60 min），预测步长 `H=6`（30 min）。

## 快速开始

```bash
# 默认：PEMS08、170 节点、L=12、H=6、batch=32、100 epochs
python src/train.py --flow data/pems08.npz --dist data/distance.csv --out runs/exp1

# 换数据集、换随机种子
python src/train.py --flow data/pems04.npz --dist data/distance.csv4 --num-sensors 307 --seed 2026
```

## 主要参数

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `--flow` | `data/pems08.npz` | 流量数据路径 |
| `--dist` | `data/distance.csv` | 距离表路径 |
| `--out` | `runs/exp1` | 输出目录（权重、日志） |
| `--num-sensors` | 170 | 使用节点数（PEMS08 为 170） |
| `--seq-length` | 12 | 历史窗口长度（5 min/步） |
| `--horizon` | 6 | 预测步长，6 对应 30 min |
| `--epochs` | 100 | 最大训练轮次，早停 patience=10 |
| `--batch-size` | 32 | 批大小 |
| `--lr` | 1e-3 | 学习率 |
| `--seed` | 42 | 语义生成与权重初始化种子 |

**关于输出**：仓库只保留训练与评估，**没有任何绘图代码，也不导出图片或 CSV**。理由很直接——不同机器跑出的数值不可能与论文表格逐位一致，仓库里堆结果文件反而容易引来质疑。所有指标（NLL、MAE、RMSE、方差、MAPE、相关系数、PICP/MPIW、不确定性分层统计）在测试结束后直接打印到终端，需要留档时自行重定向日志。

## 外部语义特征（8 维）

| 序号 | 字段 | 生成规则 |
| --- | --- | --- |
| 0 | 天气强度 | `U(0,1)` 连续值 |
| 1 | 节假日标记 | `Bernoulli(0.5)` |
| 2 | 事故标记 | `Bernoulli(0.5)` |
| 3 | 时刻编码 | 时刻经 sin 变换归一化到 [0,1] |
| 4 | 季节编码 | 年积日经 sin 变换归一化到 [0,1] |
| 5 | 暴雨标志 | 6–8 月 p=0.30，其余月份 p=0.05 |
| 6 | 事故标志 | 07:00–09:00、17:00–19:00 p=0.10，平峰 p=0.02 |
| 7 | 节假日标志 | 按日历节假日日期命中 |

第 0–2 列为基础变量，第 5–7 列为对应的事件标志；同类信息分两次编码，用于区分“状态”与“事件触发”。消融实验按组屏蔽，映射关系为：天气 `[0,5]`、节假日 `[1,7]`、事故 `[2,6]`。

生成函数见 `src/semantic.py`，固定 `--seed` 后结果可逐位复现。

## 模型要点

1. **动态邻接矩阵**：以固定距离图为基础构造邻接矩阵，按 1/(distance+ε) 加权、对称化后做最大值归一化。
2. **双通道特征提取**：图卷积聚合邻居空间信息并输出不确定性；BiLSTM 提取时序依赖；二者在特征维度拼接为时空特征。
3. **语义引导并行注意力**：语义向量与不确定性向量拼接后作为引导上下文，分别计算时间与空间注意力权重并融合。
4. **拉普拉斯混合解码**：全连接层输出 3 个分量的位置参数、尺度参数与混合权重，构成混合分布，点预测取混合期望，区间由分布分位数给出。

## 已知差异（务必阅读）

`docs/differences.md` 列出了**本仓库实现与论文正文的差异**，主要包括：动态图与论文 Pearson 逐时间步更新的差异、损失函数是否包含 MAE 与尺度正则项、图卷积层数与隐藏维、批大小与学习率调度、消融中“移除语义引导”的实际做法。投稿或开源前请按该文件核对，避免出现“论文所述与代码不符”的质疑。
